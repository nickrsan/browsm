> 3. > 4. In the table, we should note where it detects the changes from. For example https://hiddendumplinghousemidtown.com has schema.org metadata that has *different* hours than are displayed on the page. We should flag on the item that the data comes from schema.org metadata embedded in the page somehow so a user vetting the change can decide whether to rely on that, or on what they see on the page.

### Understanding & Objectives
1. **Dynamic Map Zooming & Nearby Elements Visualization on Inspection**:
   - When inspecting or selecting a POI, the vector map must automatically center and zoom in (zoom level 17), rendering the primary POI marker (or selected structure) along with all nearby API nodes and building polygon overlays retrieved from the OSM API 0.6 bounding box query.
   - When switching candidate POIs or clicking on markers/structures, the map must focus and fly directly to the selected element.
2. **Progressive Disclosure Workflow (Hide Unready Elements in Instructions State)**:
   - When the user opens the extension on a page prior to inspection or searching, the sidebar is in the `instructions` state.
   - In this state, unready elements (the vector map canvas, POI selection header, Tag Comparison Matrix, nearby place list, and action buttons) must be hidden, leaving only the header, search input, "Detected on Webpage" alert (with the "Inspect" button), and clear usage instructions.
   - When the user clicks "Inspect" or triggers an address search, the workflow transitions to the active response state where all loaded data and interactive controls are presented.
3. **Minor Tag Differences Filtering & 3-Tier Matrix Sorting**:
   - Detect cosmetic formatting discrepancies between webpage source data and live OSM data:
     - Website URLs: ignore trailing slashes (e.g. `https://example.com/` vs `https://example.com`).
     - Phone numbers: ignore hyphens, parentheses, spaces, and dots so long as the normalized dialable digits match the preferred international format.
     - Whitespace and case-insensitive boolean tags.
   - For minor differences, assign `status = 'minor_difference'`, default to `action = 'ignore'`, preserve the live OSM value in staged tags without pre-selecting it for upload, and fade the table row back with a subtle `Minor Diff` badge.
   - Sort the Tag Comparison Matrix with 3 distinct tiers:
     1. Top: Items with staged changes ready for commit.
     2. Middle: Items with minor or ignored differences.
     3. Bottom: Unchanged and identical tags.
4. **Source Provenance Annotations & Metadata Advisories**:
   - Annotate extracted tags with origin metadata (`sourceOrigin`: `'schema_org'`, `'microdata'`, `'opengraph'`, or `'manual_search'`).
   - Render origin chips in the Webpage Source column (`🏷️ Schema.org`, `🏷️ Microdata`, `🏷️ OpenGraph`, `🔍 Search`).
   - For opening hours extracted from embedded Schema.org JSON-LD markup, display an advisory warning note reminding the contributor to verify the embedded schema hours against the hours visually rendered on the webpage.

### B. Schema Parser & Tag Normalizer
- **`src/services/schema-parser.ts`**:
  - Attached `metadataSource: 'json_ld'`, `metadataSource: 'microdata'`, and `metadataSource: 'opengraph'` to parsed places.
- **`src/services/tag-normalizer.ts`**:
  - Implemented `canonicalizeWebsiteUrl()` to normalize URLs (stripping trailing slashes and lowercasing protocol/host).
  - Implemented `canonicalizePhoneDigits()` to extract dialable digits and normalize 10/11-digit North American numbers.
  - Implemented `isMinorTagDifference(key, sourceVal, osmVal)` to classify formatting-only discrepancies.

### C. Spatial Matcher Service
- **`src/services/spatial-matcher.ts`**:
  - Updated `generateTagDiff(sourceTags, targetElement, sourceOrigin, sourceNote)` to categorize minor discrepancies as `minor_difference`, default to `action: 'ignore'`, preserve the OSM value, and attach provenance fields.
  - Implemented 3-tier sorting placing staged modifications at the top, minor/ignored differences in the middle, and identical tags at the bottom.

- **`src/components/TagDiffTable.svelte`**:
