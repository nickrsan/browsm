## 2. Understanding & Architecture Analysis

### Feature 1: Periodic OSM Message Polling & Notification Badge
- **Goal**: Enable periodic checking for OpenStreetMap user direct messages and changeset discussions while the sidebar is open, and display an unread message indicator icon and badge in `AuthHeader` that links directly to the user's OSM inbox.
- **Constraints & Best Practices**:
  - **Zero Background Resource Consumption**: Periodic polling runs *only* while the sidebar is open via Svelte 5 `$effect` lifecycle hooks. When the sidebar is unmounted or closed, the timer is immediately cleared.
  - **Configurable Polling Interval**: Added `messagePollIntervalMinutes` (defaulting to 10 minutes, with options for Disabled, 5m, 10m, 15m, 30m, 60m) to `SettingsState` and exposed in Quick Settings and Options.
  - **OSM API 0.6 Response Parsing**: The OpenStreetMap API returns `<messages><received count="X" unread="Y"/><sent count="Z"/></messages>` in the `/api/0.6/user/details` XML response. Updated `getUserDetails` and added `checkUserMessages`.
  - **Reactive State & Storage Synchronization**: Added `refreshUserDetails()` to `authStore` to query the active endpoint and persist updated counts across extension surfaces.
  - **UI / UX**: Added an interactive message button with an envelope SVG icon and unread count badge in `AuthHeader.svelte`. When clicked, it opens `${webUrl}/messages/inbox` in a new tab using `browser.tabs.create`.

### Feature 2: GitHub Action PR & CI Test Workflow
- **Goal**: Create an automated GitHub Actions CI workflow triggered on pull requests and pushes that validates code quality, runs all tests, and verifies extension builds.
- **Implementation**: Created `.github/workflows/test.yml` running:
  - Checkout repository (`actions/checkout@v4`)
  - PNPM setup (`pnpm/action-setup@v4`)
  - Node.js setup with pnpm cache (`actions/setup-node@v4`)
  - Dependency installation (`pnpm install`)
  - Svelte/TypeScript type checking (`pnpm check`)
  - Vitest test suite (`pnpm test`)
  - Chrome MV3 production build (`pnpm build`)
  - Firefox MV3 production build (`pnpm build:firefox`)
