## 2. Understanding & Utilitarian Assessment

Phase 4 bridges the gap between passive place inspection and active OpenStreetMap contributions by providing:
1. **Zero-Server OAuth 2.0 PKCE Client (RFC 7636)**: Implements client-side Proof Key for Code Exchange using standard Web Cryptography API (`crypto.subtle`) for SHA-256 challenge generation. This maximizes utility and privacy by eliminating intermediate secret-holding backend servers while keeping user credentials isolated strictly in `browser.storage.local`.
2. **OSM API 0.6 Changeset Service**: Provides type-safe XML serialization for user details (`GET /api/0.6/user/details`), opening changesets (`PUT /api/0.6/changeset/create`), creating nodes (`PUT /api/0.6/node/create`), updating existing nodes (`PUT /api/0.6/node/{id}`), and modifying building structure tags (`PUT /api/0.6/way/{id}`).
3. **Non-Destructive Map Notes Submission**: Integrates Map Notes creation (`POST /api/0.6/notes`), enabling casual contributors and unauthenticated mappers to submit place suggestions and extracted business metadata without altering map geometry.
4. **Svelte 5 Reactive Auth State & UI Integration**: Implements `AuthHeader.svelte` and `NoteModal.svelte` for seamless login/logout management, user badge rendering, and rapid Map Note posting from both the sidebar workspace and popup inspector.
5. **Mozilla Add-on Policies Compliance**: Adheres to Mozilla's upcoming 2026 Add-on Policies via standard `identity` permission, strict HTTPS endpoints, and zero remote code execution.

- **`src/types/index.ts`**: Re-exported all authentication and changeset models.

### B. Core Services Implementation
- **`src/services/osm-auth.ts`**:
  - `generateCodeVerifier`: Cryptographically secure random verifier generation.
  - `generateCodeChallenge`: Base64URL-encoded SHA-256 challenge via Web Cryptography API.
  - `buildAuthorizationUrl`: Constructs standard OAuth 2.0 PKCE authorization URLs.
  - `exchangeCodeForToken`: Handles token exchange with `https://www.openstreetmap.org/oauth2/token`.
  - `loginWithOsm`: Orchestrates `browser.identity.launchWebAuthFlow`, CSRF state validation, token storage, and user profile retrieval.
  - `logoutOsm`: Safely purges credentials from local storage.
- **`src/services/osm-api.ts`**:
  - `escapeXml` and `parseXml`: Safe XML escaping and DOM parsing.
  - `getUserDetails`: Queries and parses user display name, account creation date, changeset count, and roles.
  - `createChangeset`: Serializes changeset XML with `created_by=Browsm <version>` and `source=website`.
  - `closeChangeset`: Closes open changesets.
  - `createNode` & `updateNode`: Serializes node XML for creating and updating POI elements.
  - `updateWayTags`: Serializes way XML with node references for building structure tag updates.
  - `fetchElement`: Inspects full XML for nodes, ways, and relations.
- **`src/services/osm-notes.ts`**:
  - `createOsmNote`: Dispatches Map Notes via `POST /api/0.6/notes` (attributed to authenticated user or anonymous).
  - `fetchNote`: Retrieves existing note status and community comments.
  - `formatNoteTextFromPlace`: Formats detected business attributes, address, phone, hours, and suggested OSM tags.

### C. Svelte 5 Reactive Store & UI Components

- **`src/components/NoteModal.svelte`**: Accessible modal dialog for previewing, editing, and submitting Map Notes with direct links to `openstreetmap.org/note/<id>`.
